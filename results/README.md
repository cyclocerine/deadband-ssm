# results/

Nothing here is committed: every file is regenerated by `run_pipeline.py` and
the directory is listed in `.gitignore`. The layout is stable, so a re-run
lands in the same places.

| path | produced by | contents |
| --- | --- | --- |
| `raw/<act>_f<fold>_s<seed>.json` | `--stage bench` | one cell: metrics, config, fold geometry |
| `raw/<act>_f<fold>_s<seed>.npz` | `--stage bench` | per-bar out-of-sample streams for the cell |
| `raw/<act>_f<fold>_s<seed>.pt` | `--stage bench` | the trained checkpoint the exporter loads |
| `raw/analysis.json` | `--stage analysis` | the bootstrap, DM and DSR blocks the paper quotes |
| `figures/` | `--stage figures` | PDF figures copied into `paper/figures/` |
| `sweep/<tf>/<arch>_<act>_f<fold>_s<seed>.json` | `--stage sweep` | one sweep cell |
| `sweep/all.json` | `--stage sweep` | every cell concatenated; the only input to the sweep report |
| `pilot/`, `probe/`, `smoke/` | manual runs | scratch runs kept for the record, not used by the paper |

The 40-cell grid writes 120 files (json, npz, pt) and `analysis.json`; the sweep
writes 256 cells plus `all.json`. The `.npz` files dominate the size: a 5-minute
cell carries ~430,000 bars of position and return streams.

`paper/macros.tex`, `paper/tables/results.tex`, `paper/tables/sweep.tex` and
`paper/tables/sweep_macros.tex` are generated from `raw/analysis.json` and
`sweep/all.json`. They are committed, because the paper is committed, but they
are outputs: `--stage macros` and `--stage sweep-report` overwrite them.
